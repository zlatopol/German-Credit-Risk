# Raw dataset

Папка предназначена для локального исходного датасета проекта.

Ожидаемый файл:

```text
data/raw/german_credit_data.csv
```

Сам датасет намеренно не хранится в Git-репозитории. После клонирования проекта скачайте German Credit Dataset и положите CSV в эту папку.

После этого запуск обучения:

```bash
python -m src.train
```
